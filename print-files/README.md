# Print files

Print `Box.stl`, `Cap.stl`, `Container-13.5mm.stl` and the mount for your headset from [`mounts/`](mounts).

**Atomizer holder:** print it from [Thingiverse](https://www.thingiverse.com/thing:6420549). The reservoir's 13.5 mm hole must match your holder and wick; see the [main guide](../README.md#3d-printed-parts).

**Settings:** 0.2 mm layers, 3 wall loops, 10% infill. No supports needed for the KVX parts; lay each one with its largest flat face on the build plate.

To modify the KVX parts in CAD, use the STEP versions in [`step-files/`](step-files).

The headset mounts are third-party designs and may need supports. See the [main guide](../README.md#3d-printed-parts) for credits and which ones are tested.
